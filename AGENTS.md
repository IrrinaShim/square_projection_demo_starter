# Инструкции для Codex в этой папке

Прочитай `CODEX_TASK.md`, затем `docs/TRAJECTORY_CONTRACT.md` и `docs/LEGACY_NOTES.md`. Реализуй задачу полностью и проверь запуск. Для нового расчёта основной математический источник — `docs/inverse_projection_4sat_draft.tex`.

Интерфейс получает готовый `TrajectoryResult`; орбитальная динамика и проекция вычисляются в расчётном слое. Старые исходники в `legacy/reference/` служат справкой и не являются зависимостью запуска. Различай приложенное управление и расчётное требуемое ускорение. Сохраняй порядок вершин `0-1-2-3` и явно указывай единицы всех величин.

Работай в этой папке. После реализации укажи в README команды запуска и проверок, а также научные ограничения демонстрации.
