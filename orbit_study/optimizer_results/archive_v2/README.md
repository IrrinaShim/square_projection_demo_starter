# Архив критерия версии 2

Эти файлы сохранены для воспроизводимости предыдущего этапа. В них не было
обязательной проверки направленных нормалей орбит относительно КА 0.
Приложение не загружает их как действующий кэш: ключ текущего критерия имеет
версию 3. Исходные состояния случаев N=2, 3 и 10 повторно распространены
и проверены по правилу `hᵢ·h₀>0`, угол нормалей `≤5°` на пролёте и полном
витке; новые результаты лежат на уровень выше и перечислены в `summary.md`.
