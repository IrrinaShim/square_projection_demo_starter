# Соседние пассивные орбиты: ограниченный подбор, версия 5

наклонение КА 0 равно 97,8°. Каждый КА имеет собственные состояние и
оскулирующие элементы. После эпохи — только центральное поле, J₂ и

У N=10 / 20° интерфейс с шагом изображения 5 с показывает −5…+5 с
(10 с); научная итоговая проверка с шагом 1 с даёт −6…+6 с (12 с).
Угол соседей 2° — условное требование прибора, отдельно от определения
квадрата. Для этого случая интервала с таким требованием нет.

Для малого случая использованы 12 прямых оценок, для остальных по 8.
4 КА / 20° и 3×3 / 20° сохранили ранее проверенные состояния после
повторного аудита новой версией. Новый малый кандидат получен ХКУ seed,
ограниченным конструкцией соседних орбит; новый 10×10 / 20° дал лишь
12 с. Это **первые попытки подбора**, не доказанный оптимум.
Минимальный перигей малого случая всего на 0,002 км выше принятой
исследовательской границы 500 км; для 100 КА максимальная начальная
скорость относительно КА 0 равна 0,349994 км/с при границе 0,35.
Запас по двум ограничениям мал. Условный порог сближения 1,02 км
проверен на одном полном витке для всех пар (6, 6, 36, 4950).
На всём проверенном витке каждый КА сохраняет положительное скалярное
произведение направленной нормали с КА 0 и угол не более 5°.
Многосуточная повторяемость и эксплуатационная безопасность не доказаны.

Сравнение с первым опубликованным ХКУ: пробный вариант имел 120 с
по историческим критериям формы и видимости, подобранный — 425 с.
При добавлении нынешнего допуска на **заданную внешнюю сторону** ±10%
для тех же траекторий остаётся 65 и 70 с соответственно. Поэтому
425 с не является сопоставимым требованием к независимой модели.
