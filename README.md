# Наблюдаемая сетка КА

Существующее окно показывает **один пролёт** пассивной сетки `N×N` КА (`N=2…10`). Каждый аппарат имеет собственные оскулирующие элементы на общей эпохе и независимо распространяется в нелинейной модели центральной гравитации с `J₂`, без тяги. Видимая конфигурация рассчитывается из абсолютных положений КА и наземного наблюдателя. Численные результаты исследования сохранены в [orbit_study/](orbit_study/README.md).

## Запуск и проверка

Из корня репозитория в подготовленном окружении:

```bash
.venv/bin/python main.py
.venv/bin/python -m unittest discover -s tests -p 'test_*.py' -v
QT_QPA_PLATFORM=offscreen .venv/bin/python tests/smoke_ui.py
```

Долгосрочный анализ запускается только по отдельному запросу кнопкой в окне либо командой, например:

```bash
.venv/bin/python -m orbit_study.analyze --n 2 --threshold-deg 2 --horizon-days 0.2 --output-dir orbit_study/user_runs
```

Каждый запуск создаёт отдельную папку с `case.json`, `passes.csv`, `pair_minima.csv` и графиками. Они не встраиваются в главное окно.

## Работа с окном

В поле «Режим» есть два пункта. «Без управления» загружает только **точное сочетание** `N` и заданной внешней угловой стороны из [solutions.json](orbit_study/results/solutions.json), заново рассчитывает его пролёт и показывает статус сохранённой проверки. «С управлением» оставлен для следующего этапа: совместимого рассчитанного случая пока нет; исторический CSV не выдаётся за подобранную наблюдаемую сетку. Прежние HCW, независимый сценарий из четырёх углов и исторический CSV сохранены в расчётном коде и файлах проекта для научного сравнения, но убраны из основного пользовательского сценария.

При старте выбраны **N=10 и 20°**. Для них сохранённого набора элементов **нет**: исследованный N=10 имеет целевую сторону 10°. Окно показывает причину отказа и не рисует старую траекторию под новой подписью. Поле стороны допускает 1–30°; изменение `N`, стороны или порога соседей 1°/2° немедленно пересчитывает подходящий сохранённый набор либо сообщает, что требуется новый подбор. Доступные точные пары `N: сторона` — `2:20°`, `3:10°`, `4:10°`, `5:10°`, `6:20°`, `7:20°`, `8:20°`, `9:10°`, `10:10°`. Это кандидаты ограниченного исследования, не оптимальные миссии.

Группы «Конфигурация», «Наблюдатель», «Орбита» и «Модель» показывают настройки текущего расчёта. Координаты наблюдателя, минимальный угол места, орбита и эпоха читаются из проверенных данных и не редактируются в окне. «Элементы орбит» раскрывает таблицу всех `N²` КА и позволяет экспортировать её с эпохой и параметрами опорной орбиты. Ползунок и анимация синхронизируют гномоническую проекцию, плоскость `yOz` и 3D-вид. Инерциальная камера имеет приближение к текущему положению КА 0 и отдельный общий вид с Землёй.

Локальная система имеет начало в среднем положении **всех** КА. Её оси ориентированы по мгновенным `r₀,v₀`: `eₓ=r₀/|r₀|`, `e_z=(r₀×v₀)/|r₀×v₀|`, `e_y=e_z×eₓ`. Локальные скорости включают вращение осей. Центр — расчётная точка, не новый КА и не самостоятельная кеплерова орбита. Абсолютные состояния и элементы каждого КА сохраняются; перенос локального начала не меняет проекцию наблюдателя.

**Заданная внешняя угловая сторона** `θ` определяет расстояние `α=tan θ` между соседними *крайними углами* целевого контура на гномонической плоскости. Целевые узлы имеют координаты `(αc/(N−1), αr/(N−1))`. Фактический внешний размер равен `atan` средней длины четырёх сторон крайнего контура на этой плоскости. Это не шаг соседей: минимальный **истинный** угол соседних лучей вычисляется отдельно. Под графиками углы указаны в градусах, пространственные расстояния между КА — в километрах. Стороны и диагонали крайних углов, минимум/максимум соседнего шага, максимум и минимум всех пар не смешиваются с дальностью до наблюдателя.

Зелёная полоса отмечает узлы одного пролёта, где **вся** сетка удовлетворяет условиям видимости и формы. Сохранённый минимум расстояния относится к указанному горизонту проверки всех пар, а не только к положению ползунка. Условный порог 1,02 км состоит из 0,02 км суммы радиусов КА и 1 км запаса; реальные размеры и неопределённость орбит не подтверждены. Ни один выбранный набор не удовлетворяет одновременно требованиям длительной повторяемости и безопасности на 30 сутках. Для N=10, 10° при пороге соседей 2° подходящего интервала первого пролёта нет, а минимум всех пар за сутки — около 0,0615 км. Сохранённые выводы заблокированы при несовпадении версии модели, исходных настроек или содержимого результатов.
