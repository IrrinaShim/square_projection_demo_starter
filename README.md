# Наблюдаемая сетка КА

Существующее окно показывает **один выбранный пролёт** сетки `N×N`, где `N=2…10`. В режиме «Без управления» каждый КА получает собственное инерциальное состояние и оскулирующие элементы на общей эпохе, затем независимо распространяется в модели центрального притяжения Земли, `J₂` и атмосферного сопротивления. Тяга равна нулю. Гномоническая проекция вычисляется по абсолютным положениям, а локальная система имеет начало в геометрическом центре группы.

## Запуск и проверка

Из корня проекта, используя готовое окружение:

```bash
.venv/bin/python main.py
.venv/bin/python -m orbit_study.drag_demo.run
.venv/bin/python -m orbit_study.drag_demo.controlled_check
.venv/bin/python -m unittest discover -s tests -p 'test_*.py' -v
QT_QPA_PLATFORM=offscreen .venv/bin/python tests/smoke_ui.py
cd docs
xelatex -interaction=nonstopmode -halt-on-error "Реализованная модель и исходные данные.tex"
xelatex -interaction=nonstopmode -halt-on-error "Реализованная модель и исходные данные.tex"
xelatex -interaction=nonstopmode -halt-on-error inverse_projection_4sat_draft.tex
xelatex -interaction=nonstopmode -halt-on-error inverse_projection_4sat_draft.tex
```

При запуске показан `N=10`, внешняя сторона `20°`, минимальный истинный угол соседей `2°`. [Кандидат](orbit_study/drag_demo/results/case.json) содержит 100 наборов элементов на `2026-09-28T00:00:00Z` и даёт 30 с принимаемой конфигурации на сетке изображения 5 с (33 с при проверке с шагом 1 с). На окне `−450…+450 с` уточнённый минимум среди всех 4950 пар составляет 2,458856 км. Это **частичный результат одного пролёта**, а не доказанная повторяемость или безопасность на много суток.

Изменение `N`, внешней стороны (1…30°), порога соседей (1°/2°), координат наблюдателя, минимального угла места, высоты или наклонения запускает новый ограниченный поиск и проверку одного пролёта. Для неизменного стартового случая воспроизводятся сохранённые элементы и протокол проверки. Если заданные критерии не выполнены либо высоты выходят за диапазон плотности, окно показывает отказ и фактические показатели. Зелёный участок шкалы означает геометрическую приемлемость всей сетки в показанном пролёте при применимости принятой модели плотности на всём окне. Состояния 100 КА не получаются интерполяцией готовых траекторий.

На трёх синхронных видах показаны гномоническая проекция, конфигурация `yOz` и 3D. В 3D можно приблизить группу в инерциальных координатах или вернуться к общему виду с Землёй. Раскрываемая таблица «Элементы орбит» и экспорт JSON содержат элементы каждого КА, общую эпоху и модель. Угловые размеры в градусах, физические расстояния в километрах. Условный порог сближения: 0,02 км суммы радиусов плюс 1 км запаса; реальные параметры столкновения не подтверждены.

Исследовательская плотность задаётся одной экспонентой с `ρ(700 км)=4,6·10⁻¹³ кг/м³` и `H=97 км`, используемый диапазон 500…1200 км. Сопротивление зависит от скорости относительно вращающейся атмосферы. Для этой группы масса 22 кг, площадь 0,1118202 м², `C_D=2,2` и ориентация широкой гранью к потоку являются **допущениями**, а не установленными характеристиками полётного 16U. Угол Гринвича вычисляется приближённо по GMST при `UT1≈UTC`; точное преобразование ITRF/ICRF не выполнено. Гармоники выше `J₂`, Солнце, Луна и световое давление не включены. Модель не предназначена для эксплуатационного прогноза.

Пункт «С управлением» остаётся видимым, но совместимого подтверждённого решения нет ни для одного `N`. [Исторический CSV](orbit_study/drag_demo/results/controlled_check.json) с приложенным ускорением и старые результаты `J₂` сохранены как архив, а не выданы за решения новой модели. Прежний 30-суточный анализ относится только к старому `J₂`. **Только по кнопке** создаётся отдельная папка с JSON и Markdown отчётом о запрошенном долгосрочном горизонте. Для нынешнего кандидата он фиксирует исходные элементы и причину, по которой многосуточные пролёты и сближения пока **не вычислены**: часть орбит выходит за диапазон принятой плотности вне показанного пролёта. Он не содержит вымышленных долгосрочных графиков.
