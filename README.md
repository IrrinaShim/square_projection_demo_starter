# Наблюдаемая сетка КА

Существующее окно показывает **один выбранный пролёт** сетки `N×N`, где `N=2…10`. В режиме «Без управления» каждый КА получает собственное инерциальное состояние и оскулирующие элементы на общей эпохе, затем независимо распространяется в модели центрального притяжения Земли, `J₂` и атмосферного сопротивления. Тяга равна нулю. Гномоническая проекция вычисляется по абсолютным положениям, а локальная система имеет начало в геометрическом центре группы.

## Запуск и проверка

Из корня проекта, используя готовое окружение:

```bash
.venv/bin/python main.py
.venv/bin/python -m orbit_study.passive_optimizer --n 10 --side-deg 20 --altitude-km 700 --budget 20
.venv/bin/python -m orbit_study.drag_demo.run
.venv/bin/python -m orbit_study.drag_demo.observability_regression
.venv/bin/python -m orbit_study.drag_demo.refresh_saved
.venv/bin/python -m orbit_study.drag_demo.diagnose
.venv/bin/python -m orbit_study.drag_demo.controlled_check
.venv/bin/python -m unittest discover -s tests -p 'test_*.py' -v
QT_QPA_PLATFORM=offscreen .venv/bin/python tests/smoke_ui.py
QT_QPA_PLATFORM=offscreen .venv/bin/python tests/benchmark_ui.py
cd docs
xelatex -interaction=nonstopmode -halt-on-error "Реализованная модель и исходные данные.tex"
xelatex -interaction=nonstopmode -halt-on-error "Реализованная модель и исходные данные.tex"
xelatex -interaction=nonstopmode -halt-on-error inverse_projection_4sat_draft.tex
xelatex -interaction=nonstopmode -halt-on-error inverse_projection_4sat_draft.tex
```

При запуске показан `N=10`, внешняя сторона `20°`. [Текущий результат обратного подбора](orbit_study/optimizer_results/7228a29c1e0d91f6d77c/best.json) содержит 100 наборов элементов на `2026-09-28T00:00:00Z`. После обратного подбора и повторного распространения квадратность, размер и видимость выполняются **−5…+5 с (10 с)**. Отдельный условный сценарий разрешения прибором при истинном угле соседей не менее `2°` даёт **0 с**: у нецентрированной идеальной цели минимальный угол `1,97151°`. Порог разрешения не входит в определение наблюдаемого квадрата. Обязательный критерий соседних сонаправленных орбит: для каждого КА в эпоху, на пролёте и на полном витке `hᵢ=rᵢ×vᵢ`, `hᵢ·h₀>0`, угол нормалей `≤5°`; максимум для стартового случая 2,126290° за виток. При изменении долготы восходящего узла одинаковые наклонения этого не гарантируют. Большие полуоси лежат в `7071…7155,91 км`, эксцентриситеты не превышают `0,009555`; минимум всех 4950 пар за полный виток `5,546429 км`, на показанном пролёте `25,254913 км`. Старый [кандидат без ограничений](orbit_study/drag_demo/results/case_unconstrained_legacy.json) давал 30 с красивой проекции, но имел апогей до 4745,6 км и не является проверенным решением.

Изменение `N`, внешней стороны (1…30°), координат наблюдателя, минимального угла места, UTC-эпохи, высоты или наклонения снимает старые траектории и проверяет точное совпадение с сохранённым результатом. Новый ограниченный поиск и аудит полного витка запускаются **только кнопкой «Подобрать орбиты»** в фоновом потоке. Поле бюджета задаёт число новых прямых оценок; повторный запуск продолжает исследование. Кнопка отмены останавливает поиск, уже проверенные попытки сохраняются. Окно показывает ход расчёта и игнорирует устаревший результат. Сохранённые случаи `N=2,3,10` со стороной `20°` загружаются по элементам; другой сценарий требует нового подбора. Зелёный участок шкалы означает выполненные критерии проекции всей сетки; статус полного витка показан отдельно и не стирает интервал. Внутренние точки имеют собственные состояния и распространяются независимо. Для 4 КА / 20° / 700 км получено **−55…+25 с (80 с)**, 37,630 км как минимум за полный виток и максимальный угол нормалей 2,065365°. Старый кэш версии 2 перенесён в архив и заново проверен по новому критерию.

На трёх синхронных видах показаны гномоническая проекция, конфигурация `yOz` и 3D. В ECI доступны камера, следующая за КА 0, неподвижная камера около положения КА 0 в эпоху и общий вид с Землёй; меняется только область просмотра. Точки, следы до текущего момента и красные стрелки скоростей берутся из рассчитанных состояний с одним возрастающим временем. В локальном виде стрелки используют скорости с учётом вращения осей. Раскрываемая таблица «Элементы орбит» и экспорт JSON содержат элементы каждого КА, общую эпоху и модель. Угловые размеры в градусах, физические расстояния в километрах. Условный порог сближения: 0,02 км суммы радиусов плюс 1 км запаса; реальные параметры столкновения не подтверждены.

Исследовательская плотность задаётся одной экспонентой с `ρ(700 км)=4,6·10⁻¹³ кг/м³` и `H=97 км`, используемый диапазон 500…1200 км. Сопротивление зависит от скорости относительно вращающейся атмосферы. Для этой группы масса 22 кг, площадь 0,1118202 м², `C_D=2,2` и ориентация широкой гранью к потоку являются **допущениями**, а не установленными характеристиками полётного 16U. Угол Гринвича вычисляется приближённо по GMST при `UT1≈UTC`; точное преобразование ITRF/ICRF не выполнено. Гармоники выше `J₂`, Солнце, Луна и световое давление не включены. Модель не предназначена для эксплуатационного прогноза.

Пункт «С управлением» остаётся видимым, но совместимого подтверждённого решения нет ни для одного `N`. [Исторический CSV](orbit_study/drag_demo/results/controlled_check.json) и старые результаты `J₂` сохранены как архив. Прежний 30-суточный анализ относится только к старому `J₂`. **Только по кнопке** создаётся отдельная папка с JSON и Markdown протоколом запроса на долгосрочный горизонт. Он фиксирует элементы и сообщает, что многосуточный расчёт новой модели пока не выполнен; полный виток всех пар для текущих кандидатов проверен отдельно. В основном окне показывается только один пролёт.

В [протоколе трёх случаев](orbit_study/drag_demo/results/observability_regression.json) сохранены интервалы формы и видимости, элементы, расстояния, численная сходимость и исследовательское сравнение центрирования сетки. Пробный HCW при 1,818302964° и 630 км даёт −60…+60 с; подобранный HCW даёт −215…+210 с, но это другой вариант старой модели. При независимом J₂+сопротивлении и тех же параметрах получено −36…+33 с без прохождения отдельного порога разрешения 2°. Размер 20° физически растягивает группу: в сохранённом случае 4 КА относительная скорость на эпохе достигает 0,341 км/с против 0,028 км/с для нынешнего 1,818° случая. Простое центрирование цели без ограниченного подбора орбит опускает перигей до 159 км и не принято как решение.

В [протоколе предыдущей регрессии](orbit_study/drag_demo/results/regression_comparison.json) сохранены диапазоны элементов до и после исправления. Текущий повторный замер в доступной Linux offscreen-среде: загрузка сохранённых 100 КА 4,52 с, медиана кадра 0,092 с в локальном 3D и 0,106…0,109 с в трёх инерциальных видах; событие изменения поля 0,080 с с немедленным снятием прежней траектории. Для проверки на Mac запустите `QT_QPA_PLATFORM=offscreen .venv/bin/python tests/benchmark_ui.py` либо тот же скрипт без `QT_QPA_PLATFORM` в обычном графическом сеансе.
