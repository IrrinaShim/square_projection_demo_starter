# Что именно находится в прежнем расчёте

Файлы `legacy/example_controlled/config.json`, `trajectories.csv` и `controls.csv` извлечены **из одной папки результатов** прежнего проекта `results_16u_cubedrive`. Расчёт длится от 0 до 1200 с с шагом 5 с. В файле состояний 241 строка данных; в файле управления 240 строк. Управление в строке `k` относится к интервалу от `t[k]` до `t[k+1]`.

Историческая конфигурация имеет сторону 20 км в пространстве ОСО. В `config.json` указаны высота 630 км и наклонение 97,8 градуса. Координаты и скорости трёх ведомых КА в CSV заданы соответственно в метрах и метрах в секунду; управляющий `f_i` — **ускорение в м/с²**, углы `psi_i,theta_i` — в радианах. Для построения `r_eci_km` нужно перевести относительные метры в километры, а для графика тяги оставить ускорение в м/с².

Старый порядок аппаратов:

| Исторический индекс | Начальное положение | Индекс в новом контуре |
| --- | --- | --- |
| 0, опорный | `(0,0,0)` | 0 |
| 1 | `(0,L,0)` | 1 |
| 2 | `(0,0,L)` | 3 |
| 3 | `(0,L,L)` | 2 |

Следовательно, для нового порядка обхода `0 -> 1 -> 2 -> 3 -> 0` нужно одновременно переставить **положения и управления** как `[old0,old1,old3,old2]`. Подключение старых массивов без этой перестановки даёт пересекающийся четырёхугольник и неверные подписи.

Прежний модуль `plotting.py` (в архив не включён) под словом «проекции» строил виды `xy/xz/yz` в ОСО; это не видимая проекция с Земли. Файл `shape_metrics.csv` старого проекта измерял пространственные стороны, поэтому здесь он тоже не нужен. Гномоническую проекцию прежних абсолютных положений вычисляет новый расчётный слой.

Старые CSV не содержат положения наземного наблюдателя и исходной инерциальной ориентации орбиты. В `scenarios/legacy_replay.json` для воспроизведения **назначен** зенит опорного КА в `t=600` с и координаты наблюдателя из статьи. Это явное допущение реконструкции изображения, а не воспроизведение опубликованного интервала наблюдения 386,2–511,1 с.

Исходники `legacy/reference/config.py` и `dynamics.py` включены для сверки единиц и коэффициентов. `dynamics.py` импортирует CasADi. Новый графический запуск и свободная модель должны работать без установленного CasADi. Старый код не содержит реализации обратного восстановления по видимой геометрии.
